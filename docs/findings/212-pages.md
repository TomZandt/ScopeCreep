# #212: Pages

What ticket #212 showed on 2026-11-20, at the pure layout seam (`app/tests/pages.rs`), the pure UI seam (`app/tests/page_bar.rs`, `app/tests/menu_bar_seam.rs`, `app/tests/commands_seam.rs`) and the Feed seam (`app/tests/feed_loop_seam.rs`), headless. Nothing was checked at the app: the Page bar's look, a double-click rename, the **+** menu and Ctrl+1 to 9 on a real window are still to be tried by a person.

- A page is a name, a layout tree (with its focus) and its own undo (`pages::Pages`). A new page is Empty, Default or a Copy and is shown at once. Copy asks its caller for a copy of each Panel on the page (the Window makes a duplicate and copies its settings and state), so a copy's Panels are its own; an empty copy starts with nothing to undo. There are at most 12 pages, because the Layout menu lists every page and the Window's minimum height counts it.
- Delete keeps one page and keeps the shown page where it was (deleting the shown one shows the page that took its place). Removing Panels is a sweep over every page: a further instance no page holds is removed and settings forgotten; the indices of every page's tree and undo move up together.
- The text is "pages 1", "current N" and, for each page, "page <name>" and its layout. A page whose layout cannot be read is dropped; no page left means the first-run path. Migration (no `pages` file): Main holds `panel-grid`, then each saved named layout in slot order, an empty slot adding nothing and an unreadable layout dropped. `panel-grid` and `layouts` are only read, then left alone.
- Panels the migrated layouts name are shared between pages (as the slots always shared settings); a Default page or a Copy makes its own. Closing or replacing a shared first instance on one page forgets its settings for the others too: not handled.
- Copies a saved page names ("Clean picture 2") are made again before the page is read, from every leaf name in the saved text, up to 16 per display.
- Only the shown page's shown Panels measure and draw: every other Panel is hidden through `DisplaySet::set_shown` with `Pages::live` (a Panel past the tree is hidden, not shown). The Feed seam shows a hidden Panel is handed no frame and draws nothing, and measures the frame on screen again when it comes back.
- Page bar: tabs are chips, "+" after the last and Add panel at the right end; with more tabs than room it starts at the first tab that lets the current one fit and drops what does not fit (the Layout menu lists all). The edited tab shows the typed name and a caret with no number. The Window's minimum height grows by the bar and its width counts the bar.
- Ctrl+1 to 9 are "Go to page 1 to 9". Save-into-slot Commands are gone; a saved hotkey line naming them is skipped. New page, Duplicate page and Delete page are Commands with no default hotkey. "Default layout" (menu and Command) now sets the current page to the default layout.
